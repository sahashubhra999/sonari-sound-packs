# Sonari Sound Packs

True Acoustic packs for [Sonari](https://github.com/sahashubhra999): sampled instruments the app downloads once, verifies by checksum, and keeps offline.

Packs are published as versioned release assets. The app ships a pinned manifest (URL + SHA-256 per pack), so only exact, verified bytes ever load. Nothing here runs a server; GitHub Releases serves the files.

## Packs

| Pack | Contents | Size | License |
| --- | --- | --- | --- |
| `concert-library` | 26 curated sampled instruments: orchestra, keys, and world (piano, strings, choir, brass, sitar, koto, kalimba, marimba, timpani, and more) from the MuseScore General SoundFont | ~208 MB | MIT |
